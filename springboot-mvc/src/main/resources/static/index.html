🌱 API 測試選單

路徑模式：/api/...

1. Welcome 歡迎光臨

  • 測試 /welcome
  • 測試 /home

2. Hello (@RequestParam)

  • 完整參數 (?name=John&age=20)
  • 省略選填 (?name=Mary)

3. Hi (精簡同名)

  • 測試 /hi (?name=John&age=20)

4. Lab I: BMI 計算

  • 計算 BMI (?h=170&w=60)

5. 多筆資料 (List 年齡)

  • 年齡平均 (?age=17&age=21...)

6. Lab II: 分數統計

  • 分數統計 (?score=80&score=100...)
🖥️ Response 執行結果顯示區
